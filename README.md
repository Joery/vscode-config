# vscode-config
Visual Studio Code configuration to make it clean & privacy-friendly.

## Getting Started
1. Open **Visual Studio Code**.
2. Press `Ctrl + Shift + P` to open the Command Palette.
3. Search for and select **Preferences: Open User Settings (JSON)**.
4. Replace the contents of the file with those from [settings.json](settings.json) in this repository.
5. Save the file to apply the settings.
